# Instagram — 10 günlük karusel və highlight-lar

- `916/` — 1080×1920 (9:16) slaydlar: story, reels, əl ilə paylaşmaq üçün.
- `45/` — 1080×1350 (4:5): eyni slaydlar. Instagram API (Make.com) karuseldə yalnız 4:5 … 1.91:1 qəbul edir.
- `hl/` — highlight örtükləri (`*-cover.jpg`) və story-lər (9:16).
- `tehvilaz-instagram.csv` — Google Sheet "tehvilaz" üçün cədvəl (şəkil URL-ləri, caption, status).
- `content.py` — bütün mətnlər; `render.py` — şəkilləri yenidən yaradır (`python3 render.py`).

Şəkillər bu public repo-dan `raw.githubusercontent.com` ünvanı ilə açılır; Railway deploy-undan asılı deyil.
